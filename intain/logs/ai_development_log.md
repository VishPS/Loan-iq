# AI Development Log

## Tool
Google Antigravity Agentic IDE

## Purpose
Accelerated modular ML pipeline development for the LoanIQ Data Intelligence hackathon.

## Prompt
"Build a robust XGBoost risk prediction model for next_3m_delinquency and next_12m_default, utilizing the historical monthly panel dataset."

## AI Output
Created a feature engineering module, target extraction module, and standard Train/Test split pipeline utilizing `train_test_split(test_size=0.2)`.

## Human Review
Reviewed the temporal leakage controls and the target construction logic.

## Accepted
The modular feature engineering structure and target extraction logic were accepted.

## Rejected
The initial random train-test split generated by the AI was explicitly rejected because it fundamentally violated time-aware validation protocols for financial panel data, guaranteeing future look-ahead bias.

## Corrected
Changed the validation architecture to a strict chronological split (Out-Of-Time validation), where all training records precede the validation records in time.

## Lesson
AI-generated ML code requires rigorous human validation for temporal leakage. While AI excels at boilerplate ML architecture, the nuanced financial constraints (such as sequential time-series leakage) demand strict human-in-the-loop oversight.
