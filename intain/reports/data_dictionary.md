# LoanIQ Data Dictionary

- **loan_id**: Unique identifier for the mortgage loan.
- **reporting_month**: The month the data is reported by the servicer.
- **orig_upb**: Original Unpaid Principal Balance at origination.
- **current_upb**: Current Unpaid Principal Balance.
- **dti**: Debt-to-Income ratio at origination.
- **orig_ltv**: Original Loan-to-Value ratio.
- **borrower_credit_score**: FICO score of the primary borrower.
- **dpd**: Days Past Due.
- **zero_balance_code**: Code indicating the reason the loan balance went to zero. (1=Prepaid, 3=Foreclosure, 6=Repurchase, 9=REO).
- **loan_age**: Number of months since origination.
- **bal_change_3m**: The change in unpaid principal balance over the last 3 months.
